# 模拟交易演练记录（2026-07-15）

## 1. 演练目标

- 验证下单/成交/持仓更新闭环；
- 验证风控拒单；
- 验证状态持久化（重启后恢复）。

## 2. 演练方法

- 使用 `SimulationService` 进行脚本化演练；
- 临时用固定行情（`price=42.5`）替代实时行情，以避免延时行情干扰；
- 执行顺序：重置账户 -> 风控拒单 -> 市价买入 -> 市价卖出 -> 重载服务检查状态。

## 3. 演练结果

- 风控拒单：`quantity=120` 被拒（原因：交易数量必须是100的整数倍）；
- 市价买入：`BUY 1000` 成功成交；
- 市价卖出：`SELL 500` 成功成交；
- 账户状态：`positions=1`, `orders=3`, `trades=2`；
- 持久化校验：新建 `SimulationService` 后，订单/成交/持仓均可恢复（`3/2/1`）。

## 4. 结论

- 模拟交易链路可用于周四演练和周五前预演；
- 风控规则在下单前生效；
- 持久化能力生效，满足“重启后不丢状态”的要求。

## 5. 已知限制

- 当前行情为延时近似，不可替代券商终端实时行情；
- 本周实盘仍采用人工下单，不使用自动实盘通道。

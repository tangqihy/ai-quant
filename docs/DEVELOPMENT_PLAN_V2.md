## 风险点

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 实时行情稳定性 | 模拟交易体验 | 多数据源降级、本地缓存 |
| 回测性能 | 大数据量回测慢 | 向量化计算、增量回测 |
| 前后端联调 | 接口不一致 | API 文档先行、类型定义 |
